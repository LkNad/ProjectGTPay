# План изменений системы рынка

## 1. Удаление корзины
- Удалить массив cart
- Удалить функции: addToCart, removeFromCart, updateCart, clearCart, checkout
- Удалить обработчики кнопок корзины

## 2. Изменение карточки товара
- Заменить "Добавить в корзину" на "Найти на платформе"
- Удалить "Купить все"
- Изменить отображение количества: "Лотов на рынке", "Моих лотов", "Количество в инвентаре"

## 3. Модальное окно платформы
- Уменьшенная карточка товара слева сверху
- Кнопка "Осмотреть" (открывает viewer)
- Кнопка "Продать" (открывает меню продажи)

## 4. Система продажи
- Выбор предмета из инвентаря с отображением наклеек
- Снятие брелка при продаже
- Установка цены от 0 до 1000000
- Подсказка оптимальной цены (1 лот + цена наклеек * 0.4)
- Моментальная покупка при правильной цене

## 5. Боты
- Боты покупают/продают предметы
- Боты выставляют предметы с наклейками по цене: свой лот + цена наклеек * 0.25
